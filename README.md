# TalkPulse

A real-time local chat app with a separate Express + WebSocket backend and a React + Vite frontend.

## Structure

- `backend/` — Express server, WebSocket handling, TypeScript types
- `frontend/` — React + Vite app, chat UI, WebSocket client

## Next steps

1. Install dependencies in the root workspace.
2. Build the backend WebSocket server.
3. Build the login flow and chat UI in the frontend.
4. Connect the client to the backend and test real-time messaging.
